# IA en mi aula · Biblioteca de prompts

Web con prompts para profes, listos para copiar y pegar, con buscador.

- Los prompts están en `prompts.js`. Para agregar uno, copia un bloque y pégalo arriba de la lista.
- Diseño con la identidad de IA en mi aula (paleta «Confianza cálida», Poppins y Nunito).
